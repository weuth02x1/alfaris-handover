# تسليم المهام — مجموعة الفارس

تطبيق Flutter لإخلاء الطرف وتسليم المهام: الموظف يكتب مهامه، المستلم يوافق أو يرفض، ثم المدير والموارد البشرية يعتمدون.

## الرابط العام

بعد أول بناء من GitHub Actions يفتح الموقع من:

https://weuth02x1.github.io/alfaris-handover/

ادخل بأي إيميل من الدليل التجريبي، مثل `sarah.alqahtani@alfaris.example` أو `hind.alghamdi@alfaris.example`.

## التشغيل على جهازك

```bash
cd app
flutter pub get
flutter run -d chrome
```

للجوال: `flutter run` على محاكي Android أو iPhone.
